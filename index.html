Cloud PC in a browser

Launch a lightweight Ubuntu + XFCE desktop in a GitHub Codespace, then connect to it through the browser using VNC on port 6080.

Desktop environment

Run an XFCE Linux desktop with a desktop environment that feels usable from a browser.

Development tools

Includes Python, Node.js, Git, curl, wget, and a ready-to-use dev shell.

Codespaces ready

Designed for quick setup and simple port forwarding with GitHub’s browser-based workflow.

Quick start

  • Create a repository and upload this project.
  • Open the repository in GitHub Codespaces.
  • Run the desktop helper scripts from the scripts folder.
  • Open port 6080 in the browser to access the desktop.
